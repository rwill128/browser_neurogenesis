Body-fluid coupling:
Stabilization toggle reference (what each checkbox actually does)

These toggles apply to baseline and gpu-only solver paths unless noted otherwise.

  • Warning interventions (orange): enables warning-level deformation profile handling (mainly softer spring-rest recovery tuning when warning thresholds are crossed).
  • Severe interventions (red): enables severe-collapse restabilization pass + severe recovery profile when severe deformation thresholds are crossed.
  • Post-collision recovery: runs post-collision cluster rigid-motion projection, rigid/membrane inside-correction passes, and final boundary re-bounce cleanup.
  • Soft cluster stabilizers: enables pre-collision cluster tug redistribution, relative drift damping, and ongoing cluster rigid-motion projection.
  • Soft spring-rest recovery: gradually pulls spring rest lengths back toward baseline with adaptive recovery controls.
  • Membrane boundary XPBD: applies membrane perimeter edge constraints + bend constraints (XPBD) each step.
  • Membrane shape memory: projects membrane nodes toward a rotation-aligned reference shape using per-node shape-memory weights.
  • Membrane pressure: applies membrane area/pressure preservation plus radial damping to resist collapse/over-expansion.
